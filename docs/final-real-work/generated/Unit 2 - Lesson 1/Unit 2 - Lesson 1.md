### **Lesson Plan: 中文综合课**

| **Header** | |
| :--- | :--- |
| **Unit (单元)** | 2 |
| **Lesson (课)** | 1 |
| **Topic (课题)** | 你好，我叫... (Introductions: My name is...) |
| **Objectives (教学目标)** | **Vocabulary & Grammar:**<br>- 学生能够记住并正确发音词汇 (我, 你, 他, 她, 叫, 名字)。<br>- 学生能够理解词汇的含义。<br>- 学生能够在句型和交际情境中正确使用词汇和语法 (你/他/她叫什么名字？ --> 我/他/她叫...)。<br><br>**Listening (听力):**<br>- 学生能够听辨并跟读单词或短语。<br>- 学生能够在对话中听懂并理解关键信息。<br><br>**Speaking (口语):**<br>- 学生能够清晰地发音并跟读单词或短语。<br>- 学生能够在句子中正确使用词汇和语法。<br>- 学生能够参与与老师及同学的简单对话。<br><br>**Reading (阅读):**<br>- 学生能够认读汉字 我、你、他、她、叫。<br><br>**Writing (书写):**<br>- 学生能够认识基本笔画 (捺, 点, 提)。<br>- 学生能够正确书写笔顺。<br>- 学生理解“先撇后捺”的笔顺规则。<br>- 学生能够运用笔顺规则正确描红/书写基本汉字 (我, 叫)。<br><br>**Pinyin (拼音):**<br>- 学生能够准确跟读拼音音节。<br>- 学生能够准确认读拼音 a, o, e。 |
| **Materials (教学材料)** | 拼音卡片 (a, o, e), 词汇闪卡 (我, 你, 他, 她, 叫), 手偶 (至少两个), 白板, 白板笔, 粘粘球, 汉字描红练习纸 (我, 叫), 背景音乐, 奖励贴纸。 |
| **Duration (时长)** | 45 分钟 |

### **Procedure Table (教学流程)**

| **Stage / Time (环节 / 时间)** | **Teacher Activity (教师活动)** | **Student Activity (学生活动)** | **Materials / Media (材料 / 媒体)** |
| :--- | :--- | :--- | :--- |
| **1. Warm-up (热身)**<br>**5 mins** | **1. Greeting (问候):** 老师用热情的语气向所有学生问好：“大家好！/同学们好！”<br><br>**2. Pinyin Review Game (拼音游戏):** 老师展示拼音卡片 `a`, `o`, `e`。<br> - **Echo Game (回声游戏):** 老师用不同的声调（高音、低音、机器人音、大怪兽音）读一个拼音，学生们像回声一样模仿。 | **1. Greeting Back (回应问候):** 学生们挥手并回应：“老师好！”<br><br>**2. Imitation (模仿):** 学生们集中注意力，仔细听老师的发音，并用同样有趣的声调模仿跟读，身体可以跟着节奏摆动。 | 拼音卡片 (a, o, e) |
| **2. Presentation (新知呈现)**<br>**10 mins** | **1. Introduce Pronouns (介绍人称代词):** 老师使用手偶和肢体语言(TPR)来介绍新词。<br> - 指着自己，清晰地说：“我，我，我。”<br> - 拿起一个男孩手偶，指着它说：“他，他，他。”<br> - 拿起一个女孩手偶，指着它说：“她，她，她。”<br> - 指着离自己最近的一个学生说：“你，你，你。”<br> - 重复几次，并鼓励学生跟读。<br><br>**2. Introduce Key Sentence (介绍核心句型):** 老师让两个手偶进行对话。<br> - 手偶A问手偶B：“你叫什么名字？”<br> - 手偶B回答：“我叫小明。”<br> - 然后老师对学生说：“你叫什么名字？” 引导学生尝试说出自己的名字。 | **1. Listen and Repeat (听与跟读):** 学生们观看老师演示，模仿发音。当老师指向“他”时，学生们看向男孩手偶并说“他”；指向“你”时，学生指向自己并说“你”。<br><br>**2. Listen and Answer (听与回答):** 学生们观看手偶对话，理解“你叫什么名字？”的含义。当老师提问时，学生尝试用自己的名字回答：“我叫[名字]。” | 词汇闪卡 (我, 你, 他, 她), 两个手偶 (一男一女或一中性一女性), 白板 |
| **3. Practice (练习)**<br>**15 mins** | **1. Game: Sticky Ball (粘粘球游戏):**<br> - 老师在白板上贴上几张不同人物的图片（或画出简笔画），并在旁边写上“他叫...”或“她叫...”。<br> - 请一个学生上来，扔粘粘球。球粘在哪张图片上，老师就问全班同学：“他/她叫什么名字？”<br> - 全班同学一起根据图片回答：“他/她叫[图片人物的名字]。”<br> - 然后，老师指着扔球的学生问全班：“他/她叫什么名字？”全班回答该学生的真实名字。<br><br>**2. Game: Pronoun Squat (代词蹲蹲乐):**<br> - 将闪卡“我”、“你”、“他”、“她”分别放在教室的四个角落。<br> - 老师说一个词，例如：“我！”，所有学生就要跑到“我”的卡片旁边并蹲下。 | **1. Participate in Game (参与游戏):** 学生轮流上前扔粘粘球。在扔球前和回答问题时，练习说“我叫...”。在回答同学的名字时，练习说“他/她叫...”。<br><br>**2. Physical Response (身体反应):** 学生们仔细听老师的指令，快速跑到对应的角落并蹲下。这个活动加强了对四个代词的快速反应和识别能力。 | 粘粘球, 白板, 白板笔, 人物图片/简笔画, 大号词汇闪卡 (我, 你, 他, 她) |
| **4. Production (输出与应用)**<br>**10 mins** | **1. Character Writing (汉字书写):**<br> - 老师介绍新笔画：捺 (右下斜滑)，点 (轻点)，提 (右上提)。带领学生用手指在空中“空中写字”。<br> - 老师介绍笔顺规则：“先撇后捺”，并以“人”字为例演示。<br> - 老师在白板上示范“我”和“叫”的笔顺，强调每个笔画的正确方向和顺序。<br> - 分发描红练习纸，让学生用手指描摹，然后尝试用笔描红。<br><br>**2. Role Play (角色扮演):**<br> - 让学生两人一组，用真实姓名或手偶进行对话练习。<br> - A: "你好！你叫什么名字？"<br> - B: "你好！我叫[B的名字]。" | **1. Air Writing & Tracing (空中写字与描红):** 学生跟着老师用手指在空中书写笔画。然后在自己的练习纸上，按照正确的笔顺进行描红。<br><br>**2. Pair Work (结对练习):** 学生们与同伴练习对话，轮流提问和回答。老师在教室里巡视，提供帮助和纠正。 | 白板, 白板笔, 汉字描红练习纸 (我, 叫), 蜡笔/铅笔, 手偶 |
| **5. Wrap-up (总结)**<br>**5 mins** | **1. Review Chant (复习歌谣):** 老师带领学生一起念一个简单的歌谣来复习今天的核心内容：<br> “我我我, 是我。” (指自己)<br> “你你你, 是你。” (指同学)<br> “他他他, 是他。” (指男生)<br> “她她她, 是她。” (指女生)<br> “你叫什么名字？我叫...！” (和旁边的同学一起说)<br><br>**2. Goodbye Song & Rewards (告别歌曲与奖励):** 播放或清唱“再见”歌曲，对今天表现好的学生给予贴纸奖励，并挥手说再见。 | **1. Chant & Move (念歌谣与做动作):** 学生们边念歌谣边做相应的动作，巩固所学内容。<br><br>**2. Sing and Say Goodbye (唱歌与告别):** 学生们一起唱告别歌，向老师和同学挥手说“再见！”。 | 奖励贴纸, “再见”歌曲背景音乐 |
